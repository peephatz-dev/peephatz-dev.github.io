# Peeraphat · Personal orbit

The site is a personal link hub for a first-year KMUTT builder. Its main task is to help people discover shipped work and connect.

Palette: Ice #EDF3FC, Cloud #F8FAFF, Ink #111D37, Cobalt #1550ED, Slate #52627E, Chrome #BAC8DD. Syne is the expressive display face; DM Sans is the readable UI face. Noto Sans Thai handles Thai copy.

Desktop: quiet header, left-aligned introduction beside a chrome p sculpture, then a curved fan of five useful glass links. Selected projects follow in an asymmetric editorial grid, with expandable detail dialogs. Mobile: compact art, readable introduction, a two-column link grid, then a single-column project list. All links remain accessible without dragging.

The brief's chrome-and-cloud direction overrides a generic brutalist style suggested by the initial skill search. The signature is the orbital sculpture and glass fan, rather than a generic portrait or repeated UI decorations. No invented profile photo, GitHub account, LINE contact, background audio, or availability claims.
